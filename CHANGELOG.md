# Changelog

## [Unreleased]

### Added

- Barro Slate and Barro Kaolin for favo, as custom themes in `~/.favo/themes`.
- Reading surfaces in APPS.md: how color, body text, bold, italics and code work on essays, chat replies and notes.
- TYPE.md, BRAND.md and PATTERNS.md, which document the type, the brand marks and the patterns built on Barro.
- The Irwin Arruda and The Chatbot marks, icons and avatars in `brand/`, as SVG, PNG and ICO.

## [0.1.0] - 2026-11-08

### Added

- Barro Slate and Barro Kaolin for VS Code and Cursor, with language server highlighting, rainbow brackets, diffs, the terminal and the whole interface.
- Barro Slate and Barro Kaolin for Neovim, Vim, Zed, Ghostty, OpenCode, T3 Code and Herdr.
- A palette for websites and apps, with slate, twelve steps for every Barro color and ready-to-use CSS, Tailwind and JSON files. See APPS.md.
